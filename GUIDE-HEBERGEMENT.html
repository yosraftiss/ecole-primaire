7. Rappels importants

1. Vérifier ce qui existe déjà

Cochez chaque case. Si une case ne peut pas être cochée, passez à la partie 5.

Build Command (à copier dans Render) :

npm --prefix client install --include=dev && npm --prefix client run build && npm --prefix server install

Start Command (doit aussi être dans Render) :

npm --prefix server run init-db && npm --prefix server start

2. Envoyer la version 8 sur GitHub

Cette étape remplace les anciens fichiers de GitHub par ceux de la version 8. Render se met ensuite à jour tout seul.

1

Dézipper le fichier

Faites un clic droit sur ecole-projet-v8-hebergement.zip, puis choisissez « Extraire tout ». Mettez le dossier sur le Bureau.

Vous obtenez un dossier ecole-projet. Ouvrez-le.

2

Ouvrir votre dépôt GitHub

Dans Chrome, allez sur github.com/yosraftiss/ecole-primaire (vous devez être connecté).

3

Ouvrir la page d'envoi

Cliquez sur le bouton « Add file », puis sur « Upload files ».

4

Choisir tous les fichiers de la version 8

Dans la fenêtre du dossier ecole-projet (celui du Bureau), cliquez dans un espace vide, puis appuyez sur Ctrl + A.

Glissez ensuite tous les éléments sélectionnés dans la zone de la page GitHub.

Attention : ne glissez pas le dossier C:\ecole-projet de votre PC. Il contient votre fichier de secrets server\.env, qui ne doit jamais aller sur GitHub.
5

Vérifier la liste

Attendez que la liste apparaisse en entier. Vous devez voir : client, database, maquettes, server, GUIDE-HEBERGEMENT.html, README.md et .gitignore.

6

Enregistrer l'envoi

Descendez tout en bas de la page. Laissez le texte proposé dans la zone de message, puis cliquez sur le bouton vert « Commit changes ».

Attendez que la liste des fichiers du dépôt se rafraîchisse.

7

Vérifier que le bon fichier est bien sur GitHub

Dans le dépôt, cliquez sur server, puis sur src, puis sur index.js.

Appuyez sur Ctrl + F, puis tapez dossierSite.

Si le texte est trouvé, c'est bon. Si rien n'est trouvé, recommencez l'étape 3.

3. Vérifier le déploiement sur Render

1

Ouvrir la page des déploiements

Allez sur dashboard.render.com, cliquez sur ecole-primaire, puis sur Deploys dans le menu de gauche.

2

Attendre le statut « Live »

Après l'envoi sur GitHub, une nouvelle ligne apparaît en haut de la liste. Attendez qu'elle indique Live (environ 3 à 5 minutes).

Si aucune nouvelle ligne n'apparaît après 5 minutes : cliquez sur Manual Deploy (en haut à droite), puis sur Clear build cache & deploy.

3

Contrôler les journaux

Cliquez sur la ligne du déploiement le plus récent, puis appuyez sur Ctrl + F et cherchez :

Texte à chercherRésultat attendu
built inDoit être trouvé : le site est construit.
Serveur démarréDoit être trouvé : le serveur tourne.
ATTENTIONNe doit pas être trouvé.

4. Tester le site en ligne

1

Ouvrir le site

Dans Chrome, tapez https://ecole-primaire-p8ce.onrender.com. La première fois, patientez environ une minute.

Vous devez voir la page d'accueil de l'école, avec le bouton « Se connecter ».
2

Se connecter

Cliquez sur « Se connecter », puis entrez :

Email : admin@ecole.tn Mot de passe : demo1234
Vous devez arriver sur le Tableau de bord.

5. En cas de problème

Ce que vous voyezCe qu'il faut faire
« Adresse introuvable » sur la page du site La version 8 n'est pas encore sur GitHub, ou le déploiement n'est pas fini. Refaites la partie 2, puis la partie 3.
Dans les journaux : ATTENTION : site introuvable La Build Command est incorrecte. Dans Render : Settings → Build → remplacez la Build Command par celle de la partie 1, puis Save Changes. Ensuite : Deploys → Manual Deploy → Clear build cache & deploy.
Le statut est Failed (en rouge) Ouvrez les journaux, copiez les lignes en rouge et envoyez-les pour obtenir de l'aide.
Dans les journaux : Échec de l'initialisation Dans Render, menu Environment : vérifiez que la variable DATABASE_URL est présente.
La connexion ne fonctionne pas Vérifiez l'email et le mot de passe (demo1234). Dans Environment, vérifiez que JWT_SECRET est présent.
La page met longtemps à s'ouvrir C'est normal : le site gratuit se met en veille. La première ouverture prend environ une minute.

6. Lancer le projet sur votre PC

Pour utiliser l'application sur votre ordinateur (sans Internet). PostgreSQL doit être démarré : Windows + R, tapez services.msc, puis démarrez postgresql-x64-18 s'il n'est pas en cours d'exécution.

1

Fenêtre 1 : le serveur

Ouvrez l'invite de commandes (cmd) et tapez :

cd C:\ecole-projet\server npm start

Attendez le message Serveur démarré : http://localhost:3001. Laissez la fenêtre ouverte.

2

Fenêtre 2 : le site

Ouvrez une deuxième invite de commandes et tapez :

cd C:\ecole-projet\client npm run dev

Attendez la ligne qui contient http://localhost:5173. Laissez la fenêtre ouverte.

3

Ouvrir l'application

Dans Chrome, tapez http://localhost:5173. Sur votre PC, utilisez cette adresse et non l'adresse Render.

Première fois seulement : si une erreur indique qu'un module manque, tapez npm install dans le dossier concerné (server, puis client), puis recommencez l'étape.

7. Rappels importants

Base gratuite Render : elle expire 30 jours après sa création. Si elle a été créée le 25 octobre 2026, la date d'expiration est vers le 24 novembre 2026. Après expiration, il y a 14 jours de délai, puis les données sont supprimées. Ne mettez pas de données importantes sans avoir choisi un plan payant.

Mots de passe de démonstration : ils sont publics dès que le site est en ligne. Il faudra les changer avant toute utilisation réelle.

Fichier secret : le fichier server\.env ne doit jamais être envoyé sur GitHub. Le fichier .gitignore l'empêche.

Mises à jour futures : pour publier une nouvelle version, refaites la partie 2. Render redéploie automatiquement.
